# Suggested CurseForge Listing

## Project name

DragonflightUI_Luna

## One-sentence English summary

DragonflightUI_Luna is an independently maintained compatibility fork of Dragonflight UI Classic that updates its modular Classic interface for current clients while preserving existing profiles.

## English description

DragonflightUI_Luna maintains and adapts the familiar Dragonflight UI Classic interface for players who want a modular, retail-inspired layout on World of Warcraft Classic clients. The fork keeps the established `DragonflightUI` folder and saved settings for compatibility while repairing client API changes, frame positioning, Edit Mode behavior, action bars, unit frames, party and raid frames, cast bars, buffs, debuffs, and related interface systems.

### What differs from Dragonflight UI Classic

- Current Classic Era compatibility work and protected-frame fixes.
- Repaired Edit Mode selection, movement, snapping, and saved-position behavior.
- Updated action-bar, bottom-HUD, unit-frame, party-frame, raid-frame, cast-bar, buff, and debuff behavior.
- Client-specific TOC files for Classic variants.
- Independent DragonflightUI_Luna maintenance and issue handling.
- Clear fork attribution, preserved license notices, and expanded third-party documentation.
- No in-game donation request, paywall, premium feature, or donor-only functionality.

### Installation

Extract the package so the folder `DragonflightUI` is directly inside `World of Warcraft/_classic_era_/Interface/AddOns/`. The folder name is retained because internal texture paths and saved profiles depend on it.
