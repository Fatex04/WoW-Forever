I’ve made my Luna addon compatible with **World of Warcraft: Forever**. **Dragonflight UI Forever - Luna 1.2.2** is the dedicated download for the Forever client.

**Original project:** [**Dragonflight UI Classic**](https://www.curseforge.com/wow/addons/dragonflight-ui-classic) by **KarlHeinz_Schneider**.

---

**Dragonflight UI Classic - Luna** is an independently maintained fork of **Dragonflight UI Classic** by [**KarlHeinz_Schneider.**](https://www.curseforge.com/members/karlheinz_schneider/projects) distributed under the MIT License.

Luna continues the development of the original addon because the original author has not released updates for current versions of World of Warcraft Classic. This fork extends the addon with new features, improvements, bug fixes, and updated compatibility.

Other maintainers and contributors who have continued the development of Dragonflight UI include:\
[**MendleM**](https://github.com/MendleM) Classic Era\
[**Icebreethe**](https://github.com/icebreethe) The Burning Crusade and Mists of Pandaria\
[**boang3000**](https://github.com/boang3000)\
[**iHoody**](https://github.com/iHoody)\
[**CadoCat**](https://github.com/CadoCat) Mists of Pandaria

### Installation Notice

**Remove** all other Dragonflight UI versions before installing Luna to avoid conflicts and Lua errors.

Dragonflight UI Luna is an independently maintained, unofficial fork.
